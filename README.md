# Argon2id Login/Register
Standalone browser version of the Argon2id password-hashing project. Uses Argon2id in the browser and stores only the username and Argon2id encoded hash in localStorage. No plaintext password is stored. The Argon2id library is loaded from jsDelivr, so internet access is needed when the page is opened.

Open `index.html` or publish this folder with GitHub Pages.
